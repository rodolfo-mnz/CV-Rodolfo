# Meu Primeiro Currículo Web 👨‍💻

Bem-vindo ao meu primeiro projeto de currículo online! Este foi meu teste inicial com HTML5 e CSS, onde coloquei em prática os conceitos básicos que aprendi.

## 🚀 Sobre o Projeto

Este é um currículo web simples desenvolvido como:
- Meu primeiro contato com desenvolvimento web front-end
- Exercício para aplicar conhecimentos básicos de HTML5 e CSS
- Forma criativa de apresentar minha trajetória profissional

## 🛠 Tecnologias Utilizadas
- HTML5 (semântica básica)
- CSS (estilização simples)
- Design responsivo básico

## 📌 O Que Aprendi
- Estrutura básica de um documento HTML
- Uso de tags semânticas
- Estilização com CSS
- Organização de arquivos
- Publicação no GitHub Pages

## 🤝 Como Contribuir
Como este é um projeto de aprendizado, feedbacks são muito bem-vindos! Se tiver sugestões:
1. Abra uma issue
2. Faça um fork do projeto
3. Crie um branch com sua sugestão (`git checkout -b minha-melhoria`)
4. Faça commit das alterações (`git commit -m 'Adiciona melhoria X'`)
5. Faça push para o branch (`git push origin minha-melhoria`)
6. Abra um Pull Request
